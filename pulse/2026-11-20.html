Inference & RL Infrastructure
NVIDIA explained how Dynamo, its serving layer, speeds up the rollout phase of reinforcement learning, where the model generates lots of answers before each training step. Its router sends each request to a worker that already has the right prompt cached, it ships new weights GPU to GPU as small deltas instead of full checkpoints, and it reroutes work when a worker dies. CoreWeave says weight updates got up to 15x faster. It plugs into verl, NeMo RL, Slime and prime-rl, with SGLang as the engine, and the post doesn't mention Ray. That's the RL post-training stack Ray users run today, so it's worth knowing what Dynamo is competing to own.

Security & Databases
A critical Java bug nicknamed "Java4Shell" can let attackers run code on servers without logging in. It sits in OpenJDK's Base64 decoder and hits OpenJDK 17.0.6 and later on x86 CPUs with a particular AVX-512 feature turned on. Researchers showed it against Jenkins, Kafka, Elasticsearch, Keycloak, Jira and Confluence. Patch to Oracle's November builds, or start the JVM with AVX-512 disabled until you can. (also in TLDR IT)

Security & Databases
PostgreSQL 19 is out, two months late because the team was busy fixing a wave of AI-found security bugs. The standout feature is a new WAIT FOR LSN command, which lets an app reading from a replica wait until it has caught up with a write it just made. That's "read-your-writes" without sending every read to the primary.

Finshots
Liquor stocks are falling because Indian customs stopped bulk Scotch shipments at the ports. The India-UK trade deal cut whisky duty from 150% to 75%, and companies already dropped prices by up to 7%. But customs says bulk Scotch at 62-66% alcohol is a "concentrate", not whisky, so it owes 162.5%. Allied Blenders (Officer's Choice) is most exposed, and the odd result is that importing finished bottles could become cheaper than blending in India.
