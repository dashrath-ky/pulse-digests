ByteByteGo · Wed Aug 26
A clear walkthrough of speculative decoding, the trick that makes LLMs generate text 2-3x faster. The problem is that a 70B model has to haul 140GB of weights out of memory for every single token, so the GPU's math units sit idle most of the time. Speculative decoding fills that gap by having a small model guess several tokens ahead, then letting the big model check them all in one pass. The output is statistically identical to running the big model alone.
